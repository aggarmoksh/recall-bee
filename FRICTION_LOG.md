- `2026-09-24 04:24` `[windows] [proxy] [stream]` The `taskkill /PID <pid> /T /F` fix added after the previous orphaned-bee.exe incident did NOT work -- part 2 of the answer-capture test again left 2 orphaned `bee.exe` processes (proxy + stream) running after the script exited cleanly. Root cause of the fix's failure: the script calls `proc.terminate()` + `proc.wait()` FIRST (which kills the immediate `.cmd`/node wrapper), and only THEN runs `taskkill /PID <same pid> /T /F` -- but by that point the wrapper PID is already dead and `bee.exe` has been reparented/orphaned, so taskkill's `/T` (tree) flag has nothing left to walk. Correct fix for next time: run `taskkill /PID <pid> /T /F` FIRST (while the process tree is still intact), skip `proc.terminate()` entirely, or track the real `bee.exe` PID directly (e.g. via `Get-CimInstance Win32_Process` filtered by parent PID) and kill that. Had to manually `Stop-Process -Force` both orphans again. This is now a confirmed repeatable pattern with the npm-installed `bee` binary on Windows, not a one-off.

- `2026-09-24 22:28` `[windows]` Phase 1 smoke test crashed on `ZoneInfo(settings.timezone)` with `ZoneInfoNotFoundError` / `ModuleNotFoundError: No module named 'tzdata'`. Root cause: Windows has no OS-level IANA timezone database (unlike Linux/macOS), so Python's stdlib `zoneinfo` module needs the `tzdata` PyPI package explicitly to resolve any zone by name. All the Phase 0 probe scripts happened to run fine under ad-hoc system Pythons (3.10/3.11) that already had `tzdata` installed as a transitive dependency of something else -- this fresh, clean Python 3.12 `.venv` doesn't, and surfaced the gap immediately. Fix: added `tzdata` to `requirements.txt` -- it's required on Windows for any code using `zoneinfo.ZoneInfo`, not optional. Good news: the crash also validated that `BeeProxy`'s context manager tree-kills cleanly even when an exception propagates through it (`tasklist` confirmed zero orphaned `bee.exe` after the crash) -- the try/finally pattern works as intended under real failure, not just the happy path.
